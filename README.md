# HyperTerm — Android terminal project (0.2.0)

واجهة طرفية Android داكنة بـ Kotlin، مع واجهة عربية/إنجليزية وأوامر shell متاحة داخل بيئة التطبيق.

## الحالة الحالية

هذا إصدار مصدر مطوّر مبدئي، وليس بعدُ بديلاً كاملاً عن Termux. يتضمن:
- واجهة طرفية داكنة مع سجل المخرجات وإدخال الأوامر.
- تنفيذ أوامر عبر `/system/bin/sh` ضمن صلاحيات التطبيق العادية.
- أوامر داخلية: `help`, `clear`, `pwd`, `ls`, `cd`, `echo`، مع تبديل لغة الواجهة عبر زر اللغة أو أمر `lang`.
- توضيح صريح عند طلب `python`, `python3`, `pkg` أو `apt` بأن بيئة التنفيذ غير مدمجة بعد.

## ما لم يُدمج بعد

- مفسر Python حقيقي.
- مساحة Linux userspace مع أدوات GNU/BusyBox متوافقة.
- مدير الحزم `pkg` ومستودعاته.
- عزل/تشغيل proot وتوافق معماريات ARM64/ARMv7/x86_64.
- اختبارات على أجهزة حقيقية وملف APK موقّع.

لا ينبغي تقديم هذا الإصدار على أنه بيئة Linux متكاملة قبل إضافة هذه المكونات والتحقق منها. تشغيل `/system/bin/sh` ليس هو نفسه تشغيل توزيعة Linux أو Termux.

## البناء

المتطلبات: Android Studio حديث، JDK 17، Android SDK Platform 35، واتصال إنترنت لتنزيل إضافات Gradle.

1. فك ضغط المشروع.
2. افتح مجلد `HyperTerm` في Android Studio.
3. انتظر Gradle Sync ثم شغّل التطبيق على جهاز أو محاكي.

## لماذا لا يوجد APK مرفق؟

بيئة الإنشاء المستخدمة لإعداد هذه الحزمة لا تحتوي على Android SDK أو Gradle قابل للتشغيل، لذلك لم يكن من الممكن بناء APK والتحقق منه هنا. لا تستخدم ملف APK غير مبني ومختبر على أنه جاهز.

## الخطوة التقنية التالية نحو بديل Termux

يحتاج المشروع إلى دمج بيئة Linux متوافقة مع Android (بما في ذلك bootstrap والحزم الأصلية لكل ABI)، ثم طبقة تشغيل آمنة لإدارة العمليات والملفات، وتثبيت Python ومكونات `pkg`، مع مراجعة تراخيص جميع المكونات قبل إعادة التوزيع.
